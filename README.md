# ⚡ FocusFlow

A modern productivity application designed for deep work, featuring Pomodoro timers, Kanban boards, and real-time performance analytics.

## 🎨 UI Design System
The project follows a "Technical Dark Mode" aesthetic based on the Figma design.

- [cite_start]**Primary Colors:** - Accent Pink: `#F2ACD3` 
  - [cite_start]Background: `#150926` 
  - [cite_start]Card/Widget: `#2A1440` 
- **Typography:** JetBrains Mono (Monospace)
- **Icons:** Lucide React
